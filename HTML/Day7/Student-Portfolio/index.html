Semantic HTML Elements

Semantic elements clearly describe the purpose of the content.

  • <header> - Header content
  • <nav> - Navigation links
  • <main> - Main content
  • <section> - Related section
  • <article> - Independent content
  • <aside> - Related side content
  • <footer> - Footer content

Block-Level and Inline Elements

Block-Level Elements

Examples: header, nav, main, section, article, aside, footer, h1, h2, p, ul, ol, table, form and div.

Inline Elements

Examples: strong, em, b, i, u, mark, span, a.
