FRAMEFIT - VIRTUAL EYEWEAR TRY-ON
================================

How to use:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Scroll to Virtual Try-On.
4. Click Start Camera and allow camera permission.
5. Choose frames from the Frames section.
6. The selected frame is shown over the camera preview.

Important:
- This is a front-end demo project.
- Camera access normally requires HTTPS or localhost in modern browsers.
- The frame overlay is a visual demo; production face tracking would require a face-landmark/AR library.
- No images of the user are uploaded by this demo's JavaScript.
